How Concrete generates yield

Concrete uses an ERC-4626 tokenized vault that issues ctTokens (e.g. ctUSDT, ctETH) as yield-bearing receipt tokens. An allocator role continuously rebalances capital across money markets, Pendle yield markets, Curve pools, and flash loan strategies to maximize risk-adjusted returns.

ERC-4626 vault

Single-asset, multi-strategy vault. Issues ERC-20 share tokens. Holds N strategies simultaneously. Accounting via cached totalAssets state variable — not balanceOf. Prevents inflation attacks.

Quantitative framework

TimescaleDB data pipeline. ML + stat models across 5hr–30 day horizons. C Scores (0–10 bearish→bullish). DMRA (Dynamic Market Regime Adaptation). Portfolio optimizer. Backtester. EMS (execution management).

Automated accounting

3-party system: Transaction Proposer tracks balances → Independent Signer validates → Smart contract accepts only updates within expected yield range. Monitored by Hypernative. Verified by TRES Finance.
